# VipPadelStroy CRM 🎾

REST API для управления клиентами теннисного клуба.

## 🛠 Стек

- **Python 3.11** + **FastAPI**
- **Pydantic** (валидация данных)
- **PostgreSQL** + **SQLAlchemy ORM**
- **Docker** + **Docker Compose**

## 🚀 Быстрый запуск

```bash
git clone https://github.com/Gonkong1994/VipPadelStroyCRM.git
cd VipPadelStroyCRM
docker compose up
